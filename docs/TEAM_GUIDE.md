# TEAM GUIDE

## Principios

- La documentación es parte del producto.
- Las decisiones importantes se registran.
- Los cambios deben ser pequeños y revisables.
- Ningún miembro depende exclusivamente de una conversación con una IA.
- Git es obligatorio como mecanismo de historial y recuperación.
- Lo que no sabemos del productor se marca PENDIENTE; no se supone.

## Trabajo con IA

La IA puede analizar, proponer, implementar, probar, documentar y revisar. No sustituye la aprobación humana de decisiones de arquitectura, negocio, seguridad o despliegue.

## Revisión humana

Requiere revisión humana cualquier cambio que afecte:

- arquitectura o stack;
- el significado de un evento ya guardado;
- reglas de calidad, cuarentena o intervalo de seguridad;
- permisos;
- datos personales;
- respaldos y restauración;
- lo que se entrega a un productor o a ventas.

## Comunicación

Cada tarea debe dejar un registro claro de qué se hizo, por qué, cómo se verificó y qué queda pendiente.
